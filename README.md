# English Leap Kids

A cheerful English learning game for about age **6**, inspired by **Longman English Leap 2A**.

Play five short worlds:

- School Places
- Be Good! (rules)
- Yummy Food
- How Do You Feel?
- Getting Around

Big buttons, stars, sound pops, and match / multiple-choice / fill-in games. Progress (stars & streak) is saved in the browser.

## Play online

After GitHub Pages is on:  
**https://formone98127.github.io/english-leap-kids/**

## Run locally

Open `index.html` in a browser, or:

```bash
npx --yes serve .
```

## Content note

Questions are **curated** from Leap 2A themes (school places, rules, food, feelings, travel / grammar points like *on/in*, *there is/are*, *must/mustn't*). They are rewritten for young learners — not raw OCR dumps.
